# 比特流说明

本目录**只交付一个比特流**：`hdmi_media_player_C77.bit`。

其余历史版本（C70~C79 及实验分支）不随本仓库分发；下表保留各版本的
Bitstream CRC 对照，便于判断手里拿到的 `.bit` 是哪一版。

---

## 1. 交付比特流

| 项 | 值 |
| --- | --- |
| 文件名 | `hdmi_media_player_C77.bit` |
| 字节数 | 641,264 |
| md5 | `2efc09e614929dcb8bd19a9ff02e6417` |
| Bitstream CRC | `10100010101001101100011101101011` |
| 器件 | Anlogic EG4S20BG256 |
| 生成日期 | 2026-10-30 |
| 顶层模块 | `top` |

**校验方法**

```bash
md5sum hdmi_media_player_C77.bit          # 期望 2efc09e614929dcb8bd19a9ff02e6417
grep -a "Bitstream CRC" hdmi_media_player_C77.bit
```

`.bit` 前约 140 字节是含 `# Date:` 的文本头，**重跑一次 md5 必变**。
判"两份 bit 是否同一配置"要看 `Bitstream CRC`（或确认 `cmp` 差异全部落在这 140 字节内），
比 md5 会误判成"不一致"。

## 3. 为什么交付 C77 而不是效果更丰富的 C78

C78 的观感最好、时序也最好（Setup WNS +242 ps），但底带遮罩随响度抬升在暗部经 gamma 放大后，
视觉上是"字发光时整条框跟着跳白"，实测不适。C79 修掉了跳白，却因综合网表变化引发布局连锁反应，
把 Setup WNS 打到 −232 ps、slices 涨到 89.95%（贴住 90% 红线）。

C77 是在"观感 / 时序 / 面积"三者间代价最小的解，且实测双正
（Setup +160 ps、Hold +3 ps，违例端点 0 / 0），数据见 `reports/`。

BAND_BR（底带呼吸）在源码里留了开关，置 1 即可复现 C78 的效果 —— 见
`hardware/hdmi_media_player/src/user_source/hdl_source/banner_scroll.v` 参数区注释。

---

## 4. 复现提示

C77 只能走 **`syn_1` 综合 → `phy_1` 实现** 这条路径复现。
若让 `phy_1` 自己从 `read_design` 起跑（`run_type phy` 下综合），网表的 REG 会变成 8,593 而非 8,577，
布局随之漂移，CRC 必然不同。详见 `reports/README.md` 第 7 节。
